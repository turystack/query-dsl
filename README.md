# @turystack/query-dsl

Zod schemas and serializers for type-safe HTTP query parameters.

## Installation

```bash
pnpm add @turystack/query-dsl
```

### Peer dependencies

The host application provides these:

```bash
pnpm add zod
```

## Documentation

Options, API reference and examples:

**https://tury.dev/libs/query-dsl**

## Development

```bash
pnpm install
pnpm typecheck
pnpm check
pnpm test
pnpm build
```
